Thomson Reuters, Harvey, Anthropic all verify AI output. But their verification locks you into their platform. Leave the platform, lose the verification.

We just open-sourced a better way.

The Signed Verification Receipt (SVR) is a cryptographically signed, portable, vendor-neutral verification artifact. Any platform can issue one. Anyone can verify one. No account, no API key, no walled garden.

Today we published:
- The SVR v1.0 specification (open standard)
- Verifier libraries in Python, JavaScript, and Go (MIT licensed)
- pip install svr-verify (live on PyPI now)
- JSON Schema, JSON-LD context, and OpenAPI spec
- A universal receipt renderer across 17 verticals
- Adoption guide for platforms that want to issue SVRs

We don't want to be another platform. We want to be the infrastructure that every platform uses.
