Thomson Reuters, Harvey, Anthropic, ServiceNow, Salesforce. Every platform building AI agents is now racing to solve the same problem: how do you prove the output is safe to rely on?

Their answer: build verification into THEIR platform. Leave the platform, lose the verification. That is lock-in through trust infrastructure.

We just open-sourced a different answer.

The Signed Verification Receipt (SVR) is a cryptographically signed, portable, vendor-neutral verification artifact. Any engine can issue one. Anyone can verify one. No account, no API key, no walled garden.

Every agent action should leave a receipt.

Today we published:
- The SVR v1.0 specification (open standard)
- Verifier libraries in Python, JavaScript, and Go (MIT licensed)
- pip install svr-verify (live on PyPI now)
- JSON Schema, JSON-LD context, and OpenAPI spec
- A universal receipt renderer across 17 verticals
- Adoption guide for platforms that want to issue SVRs

Do not pay for another AI answer. Pay for a receipt proving whether the answer is safe to rely on.
